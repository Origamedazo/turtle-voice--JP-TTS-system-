# turtle voice tts GUI

AIのアシストを受けて開発された、オープンソースの音声合成GUIツールです。

## 特徴
- 簡単操作で音声を合成
- 詳細なパラメータ調整（詳細モード）
- ピッチ、速度、抑揚のカスタマイズ

## 使い方
1. `run_GUI.bat` を実行して起動します。
2. セリフを入力し、再生ボタンを押してください。

## 開発環境
- Python 3.10+
- PyQt6
- NumPy, Pandas, Librosa, Sounddevice, PyWorld

## ビルド方法
1. `build_exe.bat` を実行すると `dist/` フォルダ内に実行ファイルが作成されます。
2. しかし、pythonの環境が必要なので、よくわからない方はreleaseからビルド済みのものをDLしてください
